# Transfert

Prototype front-end responsive du site de partage de fichiers.

## Contenu
- `index.html` : structure des écrans accueil, création et aperçu client.
- `styles.css` : styles et adaptation mobile.
- `app.js` : navigation, sélection de fichiers et prévisualisation locale.

## Mise en ligne sur GitHub
1. Ouvrir le dépôt `https://github.com/cyprienv/transfert`.
2. Cliquer sur **Add file**, puis **Upload files**.
3. Déposer les trois fichiers (`index.html`, `styles.css`, `app.js`) et ce README.
4. Cliquer sur **Commit changes**.

Pour activer GitHub Pages : dans **Settings → Pages**, choisir la branche `main` et le dossier `/ (root)`.

## Important
Cette version est uniquement une maquette interactive côté navigateur. Elle ne téléverse pas réellement les fichiers et ne génère pas de lien client sécurisé. La connexion OneDrive nécessite un backend séparé avec authentification Microsoft Graph et secrets conservés côté serveur.
